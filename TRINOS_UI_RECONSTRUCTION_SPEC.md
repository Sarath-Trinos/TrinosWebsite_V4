## 1. Tech Stack & Architecture

- **Framework**: Next.js 15 (App Router) + React 18 + TypeScript.
- **Styling**: Tailwind CSS 3.4, fully driven by CSS variables (HSL triples) defined in `globals.css` and surfaced in `tailwind.config.ts`. **No hardcoded hex in components** — everything routes through tokens.
- **UI primitives**: shadcn/ui (Radix-based). All primitives are client components.
- **Icons**: `lucide-react` (v0.462). Icon names cited throughout are lucide component names.
- **Fonts** (via `next/font/google`): **Inter** (body, `font-sans`), **Sora** (display/headings, `font-display`), **Poppins** (available as `--font-poppins`, used selectively). Loaded as CSS variables.
- **Animations**: CSS keyframes + Tailwind utilities + `tailwindcss-animate`; carousels via `embla-carousel-react`; charts via `recharts`.
- **Forms**: `react-hook-form` + `zod` + `@hookform/resolvers`.
- **Data/context**: `@tanstack/react-query` (QueryClientProvider), TooltipProvider, two toasters (shadcn `Toaster` + Sonner).
- **Email backend**: contact form posts to `/api/contact`, which validates with zod and sends via **Resend**.
- **Server vs client**: default to **server components**. `"use client"` only where hooks/browser APIs/Radix are used — namely `Header`, `CustomCursor`, `providers`, all `components/ui/*`, and any section using `useState`/`useEffect`/`IntersectionObserver`.
- **Path alias**: `@/*` → `src/*`.
- **Smooth scroll**: `html { scroll-behavior: smooth; }`.

### 2.7 Reusable utility classes (`globals.css`)

- **`.container-px`** → `px-6 md:px-10 lg:px-16` (standard page horizontal padding). Pages wrap content in `container-px max-w-[1400px] mx-auto`.
- **`.tile`** → `rounded-[28px] overflow-hidden relative transition-all duration-500` + `shadow-card`; on hover `translateY(-4px)`.
- **`.chip`** → `inline-flex items-center gap-2 px-3 py-1.5 rounded-full text-xs font-semibold uppercase tracking-wider`, bg `accent`, color `accent-foreground`.
- **`.link-arrow`** → `inline-flex items-center gap-2 font-semibold text-primary hover:gap-3 transition-all` (gap widens on hover — arrow "slides").
- **`.nav-link`** → animated underline: a 2px primary bar (`scaleX(0)` → `scaleX(1)` from left) appears under active/hovered nav links, transition `0.35s var(--ease-out)`. `.is-active` keeps it shown.
- **`.footer-link`** → elaborate two-stroke hover underline: a 40%-width middle segment travels left→right across the text (`@keyframes footer-link-travel`, 0.35s) then a full 2px underline draws in from the right edge (delay 0.28s); color shifts to `primary-glow`. On un-hover the underline retracts left→right.
- **`.social-ring`** → footer social icons: a circular SVG stroke (`r=17.5`, `pathLength=100`, `primary-glow`) draws **anticlockwise** around the icon on hover via `stroke-dashoffset 100 → 0` over 0.7s (SVG flipped `rotate(-90deg) scaleX(-1)`).

### 2.8 Animation library (keyframes + utilities)

| Utility | Keyframe behavior | Timing |
|---|---|---|
| `animate-float-slow` | translateY 0 → −10px → 0 | 6s ease-in-out infinite |
| `animate-fade-up` | opacity 0→1, translateY 24px→0 | 0.8s `--ease-out` both |
| `animate-marquee` | translateX 0 → −50% | 40s linear infinite |
| `animate-zoom-in-br` | from translate(60px,60px) scale .6 opacity 0 → identity | 0.6s `--ease-out` |
| `animate-expand-grow` | from translateY(−12px) scale .96 opacity 0 → identity | 0.45s ease |
| `animate-ken-burns` | scale 1.08 → 1 | 1.2s ease |
| `animate-slide-up-soft` | opacity 0 translateY18px → identity | 0.55s ease |
| `accordion-down` / `accordion-up` | height 0 ↔ radix content height | 0.2s ease-out |

**SVG-diagram keyframes** (used in agent/network/chart illustrations): `node-pulse` (scale 1↔1.15, opacity), `line-dash` (stroke-dashoffset 24→0), `packet-travel` (translateX 0→32px with fade in/out), `bar-grow` (scaleX 1↔0.92), `ring-spin-slow` (rotate 360°), `shield-glow` (opacity 0.5↔1).

**Accessibility**: `@media (prefers-reduced-motion: reduce)` disables all the above animations (including the SVG keyframes applied via inline style).

### 2.9 Custom cursor (global, pointer-fine only)

`@media (pointer: fine)` sets `cursor: none !important` site-wide and `CustomCursor` renders a two-part cursor:
- **Dot**: 10px (`h-2.5 w-2.5`) solid circle, color `#0EA5E9`, follows pointer 1:1, `z-[9999]`.
- **Ring**: 36px (`h-9 w-9`) bordered circle (2px, `#0EA5E9`), lags via lerp (factor 0.2 per frame), `opacity 0.6`.
- **Hover state** (when over `a, button, [role=button], input, textarea, select, label, summary, [data-cursor=hover]`): ring **scales to 1.6×**, opacity → 0.9, fills with `#0EA5E9` at 10% alpha (`1A`).
- Hidden until first mouse move; fades out on `mouseleave` of document. Disabled entirely on touch devices.

# SectionHeader Component (Reusable Header Component)

## Props Interface
- `eyebrow?: string` — Optional eyebrow label
- `title: ReactNode` — Main heading content (required)
- `subtitle?: ReactNode` — Optional supporting line shown under headline
- `subtitleClassName?: string` — Optional custom class override for subtitle
- `description?: string` — Optional description paragraph
- `exploreHref?: string` — Optional link href for "Explore" button
- `exploreLabel?: string` — Optional label for explore button (default: "Explore all")
- `tone?: "default" | "dark"` — Background tone control (default: "default")
- `titleClassName?: string` — Optional custom class override for title
- `headlineWeight?: "bold" | "semibold" | "medium" | "normal"` — H2 weight (default: "bold")
- `headingLayout?: "default" | "centered"` — Layout mode for heading and description (default: "default")
- `contentClassName?: string` — Applied to the column wrapping eyebrow/title/description

## Heading Weight Classes
Mapped from props.headlineWeight:
- "bold" → `font-bold`
- "semibold" → `font-semibold`
- "medium" → `font-medium`
- "normal" → `font-normal`

## Structure

### Main Container
- Classes: `flex gap-6 mb-12 flex-col`
- Conditional layout:
  - If `headingLayout === "centered"`: `items-center text-center`
  - Otherwise: `md:flex-row md:items-end md:justify-between`

### Content Column
- Conditional width:
  - If `headingLayout === "centered"`: `w-full`
  - Otherwise: `max-w-2xl`
- Additional classes: `contentClassName` prop applied here

### Eyebrow (Optional)
- Element: `<span>` with `className="chip mb-4"`
- Shown only if `eyebrow` prop provided
- Content: `{eyebrow}`

### Main Heading (H2)
- Element: `<h2>`
- Conditional classes:
  - Uses `titleClassName` if provided (full override)
  - Otherwise uses combined classes:
    - `typography.sectionHeadlineLg`
    - `{headlineWeightClass}` (from props.headlineWeight)
    - Tone-based: `text-foreground` (default) or `text-on-surface-dark` (dark)
- Content: `{title}`

### Subtitle (Optional)
- Element: `<p>`
- Classes: `mt-3 max-w-2xl`
- Typography: `typography.subheadline`
- Conditional text color:
  - Uses `subtitleClassName` if provided (override)
  - Otherwise:
    - `font-semibold`
    - `text-foreground` (default) or `text-white/90` (dark tone)
- Content: `{subtitle}`
- Only shown if `subtitle` prop provided

### Description (Optional)
- Element: `<p>`
- Classes: `mt-4 max-w-2xl`
- Typography: `typography.bodyLg`
- Conditional text color:
  - `text-white/70` (dark tone)
  - `text-muted-foreground` (default)
- Content: `{description}`
- Only shown if `description` prop provided

### Explore Link (Optional)
- Element: `<a>` tag with `className="link-arrow shrink-0"`
- Href: `{exploreHref}`
- Content: `{exploreLabel}` (default "Explore all") + ArrowRight icon (lucide)
- Icon: `w-4 h-4`
- Only shown if `exploreHref` prop provided
- Positioned on right side in default layout due to flex parent structure

### Contact API contract (`POST /api/contact`)

Validated with zod; sends email via **Resend**. Request JSON body fields:

| Field | Rules |
|---|---|
| `name` | required, 1–120 chars |
| `email` | required, valid email |
| `company` | optional, ≤200 |
| `phone` | optional, ≤40 |
| `service` | required, 1–200 |
| `message` | required, 1–5000 |

Responses: `200 {ok:true,id}`; `400` invalid JSON / invalid form data (with `issues` field errors); `500` email not configured / send failure; `502` Resend error. Env: `RESEND_API_KEY`, `CONTACT_TO_EMAIL` (default `info@trinos.ai`), `CONTACT_FROM_EMAIL`. Email is HTML (Inter font, table of fields + message) with `replyTo` set to submitter email; subject `New contact form submission from {name}`.

### Global conventions recap for the rebuilder

- Every page composes: `<Header />` (fixed, offset content with top padding in heroes) → section components → `<CTASection>` (most pages) → `<Footer />`.
- Page content width is capped at `max-w-[1400px]` with `.container-px` horizontal padding.
- Section vertical rhythm is typically `py-20` to `py-24`.
- Entrance animations are predominantly scroll-triggered via `IntersectionObserver` (reveal once visible, threshold ~0.1–0.15) applying `animate-fade-up` / `animate-slide-up-soft` / `animate-expand-grow`, often staggered by index with inline `animation-delay`.
- All motion respects `prefers-reduced-motion: reduce`.
- Custom cursor replaces the native cursor on fine-pointer devices.
- Brand blue `hsl(196 100% 47%)` and its gradients are the dominant accent; dark sections use `--surface-dark` (`hsl(222 35% 12%)`).
